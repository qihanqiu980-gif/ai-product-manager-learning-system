01

背景与求职定位

脱敏能力基础：C 端用户洞察、竞品调研、PRD、跨团队协作、A/B 实验、漏斗分析、用户增长、商业化和海外产品经验。

目标岗位：面向普通消费者或内容创作者的 ToC AI 应用产品经理，优先关注 AI 内容生产、创作者工具、AI 助手、搜索决策、交易服务和成熟产品 AI 化。

岗位结果责任

用户价值、产品体验、激活与留存、付费转化、商业化、模型调用成本、风险与合规。

能力目标

大模型认知达到 L2“方案可判”；能判断 Prompt、RAG、微调、Agent、规则与非 AI 方案的边界；能搭建独立原型、建设评测集并分析 Badcase；能讨论效果、延迟、成本、商业与风险取舍。

02

用户与主项目

项目定位：面向 AI PM 转型者的证据驱动型面试与项目答辩教练。

第一版闭环：基于真实证据的自适应面试与项目答辩训练。

首批用户

  • 零实习经验、缺少项目证据的求职者；
  • 学历竞争力较弱，需要证明实际能力的求职者；
  • 处于职业上升迷茫期、不了解岗位能力边界的实习生。

核心流程

目标岗位或 JD → 真实且脱敏的经历 → 能力考查计划 → 动态提问与追问 → 证据提取 → 结构化评分 → 风险与信息不足判断 → 复盘报告 → 可执行改进任务。

03

两周突击线

目标：14 天、约 62-80 小时，完成独立可访问的 AI Web Demo、AI PM 基础框架、Prompt / RAG / Agent / 评测 / Badcase / 风险 / 成本 / 商业化最小闭环和投递材料。

四阶段

  1. Day 1-5：旧知识核验、选型、Prompt、状态机、评分证据链；
  2. Day 6-8：独立 Web、模型 API、最小 RAG 和来源引用；
  3. Day 9-11：30+ Eval Set、Badcase、风险、成本与商业化；
  4. Day 12-14：体验修复、回归部署、PRD、视频与 8 分钟答辩。

普通学习日为 3-4 小时；第 6、7、13、14 天为集中学习日，每天 8-10 小时。

04

十二周长期线

原则：长期线完整保留。两周成果直接并入对应周次，长期线只补深度、稳定性和未通过部分。

  1. 旧知识核验、继续第 20 课、跑通平台 Agent；
  2. Transformer、Embedding 与完整方案选型；
  3. RAG、检索、重排、引用与知识更新；
  4. 自适应面试、能力覆盖、状态机与停止规则；
  5. 证据评分、Rubric、置信度与结构化输出；
  6. Eval Set、Golden Set、人工评测与 Judge；
  7. Badcase 收集、归因、修复和回归；
  8. 幻觉、长上下文、Injection、隐私与合规；
  9. 激活、留存、付费、Token 成本与商业实验；
  10. 独立 Web 工程化、API、安全代理与 RAG；
  11. 功能、边界、性能、成本、无障碍和部署；
  12. 作品集、项目答辩与目标 JD 适配。

05

掌握标准

失效规则：“询问是否懂了，学习者说懂了才继续”不能再作为掌握依据。

九项要求：英文全称、中文全称、通俗含义、基本机制、适用场景、不适用场景、主要风险、产品兜底、评测方法。

学习循环

课程讲解 → 闭卷主动复述 → 相似概念比较 → 新场景拷问 → 风险与兜底设计 → 评测设计 → 未通过则补课 → 同概念换场景重答 → 错题记录 → D+1、D+3、D+7、D+14、D+30 间隔复习。

测验每次只问一道题。只有能够准确复述、解释机制、比较边界、处理新场景、设计风险兜底并说明评测方法，才标记为“已掌握”。

06

AI 项目分析链路

项目定性 → 用户和业务问题 → 任务拆解 → AI 必要性 → 方案选型 → 不可行原因归因 → 替代方案 → 风险与兜底 → 评测验证 → 成本与商业结果。

不可行原因至少区分：模型能力、数据与知识、系统工程、产品与商业、合规与组织约束。

07

真实性与隐私红线

  • 不虚构实习、项目、职责、数据或成果；
  • 不把他人项目包装成用户经历；
  • 信息不足、资料不存在或上下文过长时不捏造；
  • 不把过期信息当作当前事实；
  • 没有证据不输出确定性评价。
内部实习材料只在本机用于抽象能力分析。课程成品、复盘文档和对外作品集不得出现内部项目原文、截图、公司数据、业务指标、链接或未脱敏事实。

08

最终交付物

独立 Web Demo、三题自适应面试闭环、真实回答引用、30+ Eval Set、Badcase 修复回归、公开知识检索与来源、成本记录、商业指标树、PRD、架构说明、评测报告、风险清单、README、演示视频和 8 分钟答辩稿。

严重事实虚构目标为 0。若某项在两周内未达标，进入长期线对应周继续补齐，不虚报完成。
