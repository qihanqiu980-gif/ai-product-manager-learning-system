## 使用方式

直接双击 `index.html` 即可离线浏览，无需启动服务器。页面使用本地 CSS、JavaScript、GSAP 与图片资源，不依赖在线 CDN。

页面均支持：

- 桌面与移动端响应式布局；
- 键盘焦点与跳过导航；
- `prefers-reduced-motion` 减少动态效果；
- 浏览器打印和“另存为 PDF”；
- JavaScript 或动画失效时仍显示完整内容。
