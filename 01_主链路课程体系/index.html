主链路 两周突击 十二周长期 复盘总结

Main learning route

一套成果，两种时间尺度。

A 轨先建立最小闭环与可展示证据；B 轨继续深化原理、稳定性、评测和迁移能力。两条路线共享同一项目与同一状态记录。

当前优先：A 轨 双轨不重复劳动 真实掌握单独核验

突击线回答“能否跑通并展示”，长期线回答“能否稳定判断、解释和迁移”。

统一产出原则

同一份 Prompt、架构、Eval Set、Badcase、成本记录和答辩材料持续迭代，不为每条路线重做一份。

双轨关系

先压缩路径，再扩大证据密度。

两周内已完成的内容直接进入长期线对应周次；长期线只处理深度、稳定性、复测与新场景迁移。

A → B · one evidence chain

最小闭环不是终点，而是长期学习的首个可验证版本。

先交付 Web Demo、评测和材料包，再用十二周补齐 Transformer / Embedding、RAG 深度、系统评测、风险治理、商业化实验与 JD 适配。

输入

现有材料

第 1-20 课、产品定义、流程、评分、PRD 与低代码配置。

A

两周冲刺

完成独立 Demo、最小 RAG、评测、风险、成本和投递材料。

B

十二周深化

补原理、系统性、长期回归、新场景与真实岗位适配。

证据

统一作品集

所有版本、测试、复盘与答辩沿同一证据链累积。

成果映射

两周交付物进入长期线的位置。

长期线不重复做已经验证过的基础版本，只在相应周次升级质量和能力证据。

状态规则

课程进度、项目进度、掌握进度分别记录。

这避免“文件已经有了”被误认为“已经能够在新场景中做判断”。

已有材料

文件存在、讲过或做过平台配置。

待复核

需要闭卷、边界与新场景重新验证。

待巩固

方向基本正确，但机制、风险或评测不全。

复测中

补课后等待同概念换场景重答。

已掌握

九项标准均形成主动输出证据。
