先在脑中搭起一张图：商业化不是“AI 功能上线后找人付费”。

AI 产品商业闭环可以先理解为“用户用 AI 做成一件有价值的事，并且这件事产生的收入或留存价值大于模型、人工、获客和风险成本”。指标要从一次成功任务开始，沿着回来使用、愿意付费、成本控制和实验验证往下走。

先讲业务动作，再讲指标名

每个指标都先回答“用户做成了什么、为什么愿意回来、为什么愿意付钱”。

用错误增长划边界

不把点击、试用和模型调用量当成商业成功，而是找到第一个没有产生价值或毛利的节点。

激活是不是用户点了“生成”按钮？

激活可以先理解为“用户第一次用 AI 做成有价值的任务”。点击按钮只是尝试，真正的激活要看到用户拿到了可用结果，或完成了原本更费时的工作。

0 / 2 步

Value Action

就是用户真的完成的价值动作

例如生成可提交的 JD 分析，而不是只打开页面。

能决定：是否进入激活不能决定：是否愿意付费

Time-to-Value

就是多久拿到第一次价值

从进入产品到得到可用结果的时间。

能帮助：发现上手阻塞不能替代：结果质量

Activation Gate

就是激活门槛

必须足够接近业务价值，不能只是低成本点击。

能阻止：虚高数据不能证明：长期留存
白话解释

激活像第一次真正吃到产品的好处。用户只是点了按钮，还不算；用户拿到能用的方案、报告或节省了明确时间，才接近激活。

它不等于什么

注册、浏览、点击生成、调用模型都不是天然激活。它们可能只是好奇或误触。

看起来增长，但错误点击生成率 80% → 激活很好

不知道生成结果是否被采用，也不知道用户是否获得价值。

正确的产品链路关键任务 → 可用结果 → 用户采用/保存 → 激活

把激活定义到业务结果上。

完整示范：简历优化助手先定义采用动作

现象：用户点击“优化简历”很多，但很少复制或保存结果。

  1. 已知事实点击发生了，但结果没有进入用户求职流程。
  2. 第一个错误节点把模型调用当成激活。
  3. 正确动作改成“生成后保存一版并修改至少一个段落”作为激活候选。
  4. 保持不变激活必须绑定用户第一次获得可用价值。
理解检查：哪个更像激活

简历助手上线后，用户大量点击生成，但很少保存结果。第一步应该怎么改指标？

留存是不是用户下周又打开了 App？

留存可以先理解为“用户把产品放进重复发生的任务里”。只打开 App 可能是提醒、误触或看通知；真正的留存要看用户是否回来完成同类价值动作。

0 / 2 步
白话解释

留存像用户把工具放进日常流程：每周写周报、每次投递前练面试、每次客服争议先查知识库。

它不等于什么

DAU、打开率和消息点击不是天然留存。AI 产品更要看任务频率和价值动作是否重复。

看起来活跃，但错误7 日打开率高 → 留存好

打开不代表完成价值任务。

正确的产品链路任务周期 → 重复价值动作 → 质量/成本稳定 → 留存

用任务复用判断留存。

完整示范：AI 周报助手先看任务周期

现象：用户每天打开页面，但只有月底生成过一次周报。

  1. 已知事实打开频繁，但周报任务没有按周重复。
  2. 第一个错误节点把打开当成工作流复用。
  3. 正确动作观察用户是否每周导入材料、生成、编辑并发送周报。
  4. 保持不变留存要匹配任务自然频率。
理解检查：打开率能不能当留存

AI 周报助手 7 日打开率很高，但用户没有持续生成周报。第一步应该怎么改留存定义？

请为“AI 客服质检助手”设计留存指标，写清任务周期、复用动作、分群和退化信号。

需要提示时展开

客服质检可能按日、按班次或按工单批次复用，和普通日活不同。

方案已记录。

留存可按“每个工作日上传工单批次并处理质检报告”定义，分客服主管、质检员和业务负责人看复用；退化信号包括只上传不看报告、报告无标记、人工复核比例升高、连续两个质检周期未处理高风险工单。

留下一个理解或疑问

付费是不是把免费额度用完后弹窗收费？

付费可以先理解为“用户愿意为确定价值、节省时间、降低风险或提高产出质量付钱”。收费点要贴近价值完成，而不是简单卡住用户。

0 / 2 步
白话解释

好的付费点像升级工具箱：用户已经看到价值，愿意为更多次数、更高质量、更低风险或团队协作付费。

它不等于什么

“用到一半强制付费”可能提高短期转化，也可能破坏激活和留存，尤其是用户还没看到价值时。

看起来能赚钱，但错误首个结果生成前弹付费

用户还没体验价值，转化和信任都会受损。

正确的产品链路价值已发生 → 升级权益 → 价格锚点 → 付费验证

让付费连接到可感知价值。

完整示范：求职辅导助手先看价值门槛

现象：用户刚上传简历，系统还没给反馈就要求订阅。

  1. 已知事实用户尚未看到 AI 能改善什么。
  2. 第一个错误节点在价值出现前收费。
  3. 正确动作先给一份基础诊断，再为深度岗位匹配、模拟面试和持续跟踪收费。
  4. 保持不变付费点要靠近用户已确认的价值。
理解检查：什么时候弹付费

求职助手在用户刚上传简历、还没看到反馈前弹订阅。第一步应该怎么改？

需要提示时展开

免费层要足够完成第一次价值；付费层可以是更深反馈、长期追踪、更多复测或作品集导出。

方案已记录。

免费层可提供一次完整诊断和一条改进建议；付费层提供多轮复测、长期学习计划、错题追踪、作品集导出和更高质量模型。升级触发点应在用户保存诊断或完成首次复测后，而不是首次进入页面前。

留下一个理解或疑问

Token 成本是不是只看每次调用多少钱？

Token 成本可以先理解为“每次 AI 帮助背后的可变成本”。它不只包括输入输出 Token，还包括重试、长上下文、工具调用、缓存、人工复核和失败补偿。

0 / 2 步
白话解释

Token 成本像每单外卖的食材和配送费。订单越多不一定越赚钱，如果每单成本超过收入，增长越快亏得越快。

它不等于什么

只看模型 API 单价不够。长文档、反复重试、低质量导致人工兜底，都会进入单位成本。

看起来便宜，但错误一次调用 0.05 元 → 毛利没问题

忽略长上下文、重试、失败和人工复核。

正确的产品链路每次任务收入 → Token/工具/人工/风险成本 → 毛利

按完整任务算单位经济。

完整示范：长文档总结套餐先算每个成功任务

现象：产品按每份报告 1 元收费，但每份平均 4 次模型调用、一次长上下文和 20% 人工复核。

  1. 已知事实单次调用便宜，但完成一份报告有多项成本。
  2. 第一个错误节点用一次调用成本替代一次成功任务成本。
  3. 正确动作按完成报告计算 Token、重试、人工、失败补偿和支付成本。
  4. 保持不变商业判断要看单位任务毛利。
理解检查：每次调用便宜就够了吗

每次模型调用只要 0.05 元，但一份付费报告平均要 4 次调用和人工复核。第一步应该怎么算？

先以一次成功合同摘要为单位，而不是一次 API 调用。

单位成本表应以“完成一份可交付合同摘要”为单位：收入、输入 Token、输出 Token、长上下文或 RAG 检索、平均重试次数、缓存命中抵扣、人工抽检比例、失败退款和支付成本，最后计算单份毛利和毛利率。

留下一个理解或疑问

模型路由是不是贵模型效果最好就全用贵模型？

模型路由可以先理解为“不同任务用不同成本和能力的模型”。简单任务用便宜模型或规则，高风险复杂任务用强模型或人工；目标是让足够好的结果以可承受成本交付。

0 / 2 步
白话解释

模型路由像交通出行：附近买菜不必坐商务舱，跨城出差也不能只骑共享单车。任务风险和价值决定路线。

它不等于什么

全用最强模型不是稳妥商业化；全用最便宜模型也可能因质量差、人工兜底和流失而更贵。

看起来高质量，但错误所有请求 → 最高级模型

简单任务成本过高，毛利被吃掉。

正确的产品链路任务分层 → 质量门槛 → 成本预算 → 路由规则

按任务选择规则、便宜模型、强模型或人工。

完整示范：客服助手路由先分任务层

现象：所有 FAQ、退款争议和投诉都走同一个强模型。

  1. 已知事实FAQ 低风险高频，退款争议高风险，投诉需要人工可能性高。
  2. 第一个错误节点按统一模型处理不同价值和风险任务。
  3. 正确动作FAQ 走规则或便宜模型，高风险争议走强模型加人工，投诉直接转人工队列。
  4. 保持不变路由要同时看任务价值、风险、质量和成本。
理解检查：所有任务用强模型吗

客服助手把所有 FAQ 和高风险退款争议都交给最贵模型。第一步应该怎么改？

留下一个理解或疑问

商业实验是不是 A/B 看哪个转化率更高？

商业实验可以先理解为“用受控方式验证价值、收入、成本和风险的变化”。AI 实验不能只看点击或转化，还要看结果质量、Token 成本、人工介入、退款和长期留存。

0 / 2 步
白话解释

商业实验像试开一家店：不只看进店人数，还要看成交、毛利、退货、投诉和用户会不会回来。

它不等于什么

“付费按钮点击率更高”不等于实验成功。如果成本上升、退款增加或留存下降，商业结果可能更差。

看起来胜出，但错误转化率 +20% → 上线

没有看成本、质量、退款和长期留存。

正确的产品链路假设 → 指标组 → 成本/风险护栏 → 实验决策

把增长指标和护栏指标一起看。

完整示范：强模型试验先设护栏

现象：强模型让付费转化提升 8%，但每单成本翻倍，人工投诉也上升。

  1. 已知事实收入指标变好，但成本和风险指标变差。
  2. 第一个错误节点只看转化率，忽略单位经济和质量护栏。
  3. 正确动作比较毛利、留存、退款、投诉和高风险 badcase，再决定灰度或回滚。
  4. 保持不变AI 商业实验必须同时看价值、成本和风险。
理解检查：转化更高就上线吗

强模型实验付费转化提升，但每单成本翻倍，投诉增加。第一步应该怎么判断？

留下一个理解或疑问

综合工作坊：修好一个“用户量增长但越做越亏”的 AI 产品方案。

这不是记忆测试。你可以回看任意模块、打开提示并修改方案。目标是把激活、留存、付费、Token 成本、模型路由和商业实验连成一套可判断的单位经济方案。

错误方案：AI 简历助手把“点击生成”当激活，把“7 日打开”当留存；免费用户可无限用强模型；付费点在用户看到反馈前弹出；只看订阅点击率，不看 Token、重试、人工复核、退款和留存；所有任务都走最贵模型。
