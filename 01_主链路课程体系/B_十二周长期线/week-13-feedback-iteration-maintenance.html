把 W13 理解成一条反馈迭代链：先把投递和面试信号记录成事实，再判断哪个缺口最影响岗位匹配；然后改作品集版本、做小批量投递实验、安排能力补证，最后用每周节奏保持更新。

先讲事实，再讲情绪

每条反馈都先写清来源、岗位、问题、证据和下一步，不把一次拒绝当成能力结论。

用版本管理作品集

不把作品集改成越来越厚，而是记录每次改版解决了哪个追问或岗位缺口。

带着实验节奏行动

每周小批量投递、复盘、补证和改版，避免盲目海投或反复重学。

反馈记录可以先理解为“把外部信号写成可复盘事实”。它不是情绪日记，也不是只记结果，而是保存岗位、材料版本、追问、反馈证据和下一步。

白话解释

每一次投递和面试都像一次小实验。你要记录用了哪个作品集版本、投给什么岗位、对方问了什么、哪里卡住，下一次才知道该改材料、补证据还是换岗位方向。

它不等于什么

它不等于“今天又失败了”或“感觉岗位不匹配”。没有来源和材料版本的反馈，无法指导下一轮行动。

看起来真实，但错误今天没回音 → 我不适合 AI 产品

先记录事实，再做判断。

  1. 已知事实追问集中在 W6 评测设计，不是所有能力都失败。
  2. 第一个错误节点把具体追问泛化成自我否定。
  3. 正确动作记录岗位、材料版本、原追问、自己回答、卡点和下一轮观察。
  4. 保持不变外部反馈必须先变成可复盘事实，才进入缺口排序。

留下一个理解或疑问

所有反馈都要马上修吗？

缺口排序可以先理解为“判断哪个问题最影响下一步”。反馈可能是表达不清、证据不足、能力没补、岗位不匹配或样本太少；不同原因对应不同动作。

0 / 2 步
白话解释

把反馈当成待分诊的工单。先判断它属于材料表达、项目证据、真实能力、岗位方向还是实验样本不足，再决定改一页、补一张证据表、做一次复测或换目标岗位。

它不等于什么

它不等于来一个意见就改一次作品集，也不等于忽略刺耳反馈。没有排序会让你一直忙，但能力证据没有变强。

看起来勤奋，但错误每收到一个建议 → 全部材料重写

改动很多，但不知道哪个改动解决了哪个问题。

正确的产品链路反馈分类 → 影响评估 → 证据优先级 → 单次改动

一次只处理最高优先缺口。

完整示范：三次追问都卡在成本先升优先级

现象：三次模拟面试都被追问 Token 成本和模型路由，你每次只把作品集封面改得更好看。

  1. 已知事实反馈集中在商业和成本证据，不是视觉问题。
  2. 第一个错误节点把高频证据缺口误判成展示问题。
  3. 正确动作把单位经济、路由阈值和成本护栏列为本周最高补证项。
  4. 保持不变重复出现且影响岗位匹配的证据缺口优先级最高。
理解检查：三次都被问成本怎么办

需要提示时展开

看两件事：它是否反复出现；它是否直接影响目标岗位能力证明。

方案已记录。检查是否把“情绪最强”与“影响最大”分开。

示例：成本追问重复出现且 JD 要求商业判断，列为最高优先；“页面不好看”若只出现一次且未影响理解，先记录不立刻重做；“不会解释 Eval set”属于能力和表达双缺口，需要补证加口述练习。

它不等于什么

它不等于把所有新材料都塞进主线，也不等于每次都换视觉风格。版本没有改动原因，就无法复盘。

让别人只看版本记录就知道这次改动解决什么追问。

示例：portfolio-v1.3-cost-route，触发反馈是三次追问“为什么不用强模型”。改动：新增单位成本、模型路由阈值和灰度条件页。证据位置：W9 成本表、W11 成本护栏、W12 答辩卡。验证：下 5 次模拟面试是否还能讲清成本口径。

留下一个理解或疑问

投递是不是越多越好？

投递实验可以先理解为“小批量验证材料和岗位匹配”。一次只改一个变量，比如岗位方向、简历标题、作品集入口或答辩主线，再观察回复、追问和转化。

0 / 2 步
白话解释

把投递当成产品实验，而不是情绪消耗。每批数量小一点，目标清楚一点，版本固定一点，才知道是岗位方向不对、材料没讲清，还是样本太少。

它不等于什么

它不等于一天海投 100 个岗位，也不等于改完作品集立刻期待确定结果。小样本只能提供信号，不能证明最终成败。

看起来努力，但错误海投大量岗位 → 没回复 → 全盘否定

变量太多，无法知道问题出在岗位、渠道、材料还是市场。

正确的产品链路假设 → 小批量 → 固定版本 → 观察指标 → 下轮调整

让投递成为可学习实验。

完整示范：只测作品集入口先固定变量

  1. 已知事实多个变量同时变化，无法归因。
  2. 第一个错误节点把投递当成数量游戏而不是实验。
  3. 正确动作下一批固定岗位和简历，只测试作品集入口文案，记录打开、回复和追问。
  4. 保持不变小批量实验一次只验证一个主要假设。

它不等于每天焦虑刷岗位，也不等于把页面完成状态说成正式能力。长期节奏的价值在于稳定收集证据和减少盲目改动。
